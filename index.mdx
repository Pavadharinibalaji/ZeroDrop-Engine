# ZeroDrop Engine

**Engineering reliable inventory reservation under high concurrency.**

ZeroDrop Engine is an individual software engineering project focused on designing and developing a high-concurrency inventory reservation and order management system.

The goal is to investigate how backend systems can process competing purchase requests safely, maintain inventory consistency, and handle traffic spikes through efficient database operations and distributed processing.

<Note>
  This project is currently in its planning and design stage. Architecture decisions, implementation details, and performance results will be documented as development progresses.
</Note>

## The Problem

Imagine an e-commerce flash sale where a limited quantity of products becomes available to thousands of customers simultaneously.

The system must ensure that:

- Inventory never becomes negative.
- Available stock is not allocated multiple times.
- Duplicate checkout requests do not create duplicate orders.
- Failed reservations and payments are handled correctly.
- The backend remains reliable under concurrent workloads.

## Project Objectives

1. Design a transaction-safe inventory reservation mechanism.
2. Understand and implement concurrency control.
3. Build REST APIs using Java and Spring Boot.
4. Design an optimized PostgreSQL database schema.
5. Explore Redis-based caching and distributed coordination.
6. Introduce asynchronous order processing using Apache Kafka.
7. Evaluate performance through repeatable load tests.

## Engineering Principles

**Correctness before performance**

The system must preserve inventory correctness before attempting throughput optimization.

**Measure before optimizing**

Performance improvements must be supported by repeatable experiments.

**Document engineering decisions**

Important architectural choices, alternatives, failures, and trade-offs will be recorded throughout development.

**Understand before implementing**

Every major feature should be explainable independently, without relying on generated code.

## Project Development Stages

4. Concurrency and transaction testing.

6. Performance evaluation and deployment.
